# Finance Tracker AR

Arabic personal finance tracker for managing monthly income, expenses, budgets, and spending categories.

## Features

- Add, edit, and delete transactions
- Track income and expense totals by month
- View running balance and monthly summary
- Search and filter transactions
- Category-based expense chart
- Monthly savings/target tracking
- Persistent storage with SQLite database
- Responsive Arabic UI
- Android APK build support via Capacitor

## Tech Stack

- Node.js + Express
- SQLite via better-sqlite3
- Vanilla frontend with Tailwind CSS and Chart.js
- Capacitor for Android packaging

## Requirements

- Node.js 18+

## Install

```bash
npm install
```

## Run locally

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

## API

The app includes a local API for data access and persistence.

### Health check

```bash
curl http://localhost:3000/api/health
```

### Transactions

```bash
curl http://localhost:3000/api/transactions?month=2026-09
```

### Summary

```bash
curl http://localhost:3000/api/summary?month=2026-09
```

## Build Android APK

Make sure Android Studio and the Android SDK are installed, then run:

```bash
cd D:\finance_tracker_ar
npx cap sync android
cd android
./gradlew.bat assembleDebug
```

The APK appears at:

```text
D:\finance_tracker_ar\android\app\build\outputs\apk\debug\app-debug.apk
```

## User Guide

### 1. Add a transaction

- Fill in the description, amount, type, and category
- Press the add button
- The transaction is saved automatically

### 2. View monthly data

- Use the month arrows to move between months
- The running balance, income, expenses, and chart update for the selected month

### 3. Search and filter

- Use the search field to find transactions by description or category
- Click filter buttons to see all, income, or expenses

### 4. Edit or delete

- Press the pencil icon to edit a transaction
- Press the trash icon to delete it

### 5. Set preferences

- Monthly target: set a target spending limit
- Currency: choose the display currency
- Theme: switch between light and dark mode

### 6. Database persistence

- Transactions are stored locally in SQLite database files under the `data/` folder
- The data remains available after app restarts

## Notes

- This is a local desktop/mobile-friendly app designed for personal use.
